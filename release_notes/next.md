# DesktopWidget 1.0.51
## Updated UI
- The ui has received some updates
- bigger buttons
- media player has a nicer design
- every widget now shares the media player's look: same header, status label and round + button
- new app picker with an icon grid, multi-select, a Games tab and drag & drop
- System stats tiles redesigned and no longer cut off
- files in the Documents widget show their real icons
- optional anonymous usage stats (can be turned off in Settings > System) and an occasional feedback card

## Bug fixes
- Fixed a bug where some icons were not loading properly
- Fixed apps added by drag & drop showing a letter instead of their icon
- updated handler of executables in folders
